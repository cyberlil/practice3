# Задание 1. Сортировка капель в колбах

## Запуск:

```cmd
cd ./test_tasks 
gradle build
gradle run
```

## Ввод параметров для генерации колб:

- Введите количество колб N: (N > 0)
- Введите количество цветов M: (M < N)  
- Введите объем колбы V: (V > 0)

## Правила:

- В каждой колбе может быть жидкость разных цветов
- За один ход можно переливать только верхние капли одного цвета
- Переливать можно только в колбу с таким же цветом сверху или в пустую колбу
- Цель: отсортировать жидкости так, чтобы в каждой колбе был только один цвет
